# Arista portfolio

A static portfolio starter using HTML and CSS. The project content is explicitly marked as coming soon; the abstract illustration is made with CSS.

## Preview locally

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

## GitHub Pages

Repository: https://github.com/AriaNaseri/arista.github.io

In Settings → Pages, choose **Deploy from a branch**, **main**, and **/ (root)**. Save. The site will be available at https://arianaseri.github.io/arista.github.io/ after a successful deployment.

Edit `index.html` for content and `styles.css` for presentation. All links and assets use relative paths to work under the repository's URL path. No external assets or build tools are required.
